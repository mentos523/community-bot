# 常见问题（FAQ）

> 按"我想…"和"我遇到了…"两种句式找答案。看不懂的词先查 [术语表](术语表.md)。

## 我想…

### 我想在 Windows 上用
看 [安装指南](安装指南.md) 的 Windows 章，从装 Python 开始一步步来。
记得装 Python 时勾选 **"Add python.exe to PATH"**。

### 我想让机器人 24 小时运行
电脑不要关机、不要休眠。`start.sh` / `start.bat` 启动后保持黑窗口开着就行。
想更省心可以了解系统的"开机自启动"，这个超出本指南范围了。

### 我想换个 AI 模型
Web 界面 → 模型管理 → 点"查找已下载的模型"（电脑里装了 Ollama 的话），
或手动添加。加好后去"社区管理"里给社区换上，保存即生效。

### 我想让机器人少回一点 / 多回一点
Web 界面 → 全局设置 → "全站每日最多回复"，默认 20 条，改成你想要的数字就行。

### 我想看机器人今天回了什么
Web 界面 → 日志查看。日志是给懂技术的人看的，
看不懂就把出错的那段复制下来发给帮你装的人。

## 我遇到了…

### 我遇到了：`pip` 不是内部或外部命令
**原因**：没装 Python，或者装的时候没勾选 "Add python.exe to PATH"。
**解决**：去 https://www.python.org/downloads/ 下载安装，
安装界面底部**一定要勾选** "Add python.exe to PATH"，然后重装一次。
装完在黑窗口输入 `python --version`（Windows）或 `python3 --version`（Mac/Linux），
看到版本号才算成功。

### 我遇到了：配置文件写错了（一大段中文提示）
**原因**：YAML 格式写错了，最常见的是这三个：
1. 冒号后面没加空格：写 `port: 52323`，不要写 `port:52323`
2. 用了 Tab 缩进：只用空格，不要用 Tab 键
3. 用了中文冒号：用英文的 `:`，不要用中文的 `：`

**解决**：按提示找到那一行改过来。也可以把文件内容粘贴到
https://www.yamllint.com 在线检查，它会指出哪行错了。

### 我遇到了：Web 打不开 / 登录不上
按顺序查：
1. **设密码了吗？** 启动 Web 的那个窗口里要先设 `WEB_PASSWORD`
   （Windows 用 `set`，Mac/Linux 用 `export`，见[安装指南](安装指南.md)对照表）。
   没设的话页面会锁定，直接告诉你该输什么命令。
2. **端口被占了吗？** 如果提示"端口 52323 已被占用"，换个端口
   （改 `config.yaml` 里的 `web.port`）或关掉占用它的程序。
3. **地址对吗？** 默认只监听本机，用 http://127.0.0.1:52323 打开，
   不要用别的 IP。

### 我遇到了：机器人不回复了
按顺序查：
1. **守护进程还在跑吗？** 启动机器人的那个黑窗口还在吗？关了就没了，重新运行 `start.sh` / `start.bat`。
2. **Token 过期了吗？** 去平台重新申请一个 Token，填到 Web 的社区配置里。
   日志里看到 401 / 403 就是这个意思（"登录过期了"）。
3. **今天 20 条用完了吗？** 默认每天最多回 20 条，用完就等明天，
   或去全局设置调大。
4. **Ollama 在运行吗？**（用的本地模型的话）黑窗口输入 `ollama list`，
   没反应就是 Ollama 没启动，先运行 `ollama serve`。

### 我遇到了：Ollama 点"查找已下载的模型"没反应
1. 先确认 Ollama 在运行：黑窗口输入 `ollama list`，能看到模型列表才行。
2. 没启动的话先运行 `ollama serve`（Linux/Mac），Windows 版装完一般是自动启动的。
3. 还不行就检查 `endpoint` 是不是 `http://localhost:11434`。

### 我遇到了：`ollama pull` 下载一半不动了
**原因**：模型文件很大（qwen2.5:7b 约 4.7GB），按网速要 10-30 分钟，
中途不要关机、不要断网。
**解决**：耐心等。Ctrl+C 中断后可以重新运行 `ollama pull`，它会接着下，
不会从头开始。记得预留至少 10GB 磁盘空间。
