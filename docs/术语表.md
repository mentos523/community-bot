# 术语表（大白话版）

文档里看到不认识的词，来这查，一句话讲明白。

| 词 | 大白话解释 |
|----|-----------|
| 守护进程 | 一直在后台运行的程序，不用你盯着，7×24 小时自己干活。关掉黑窗口它就停了。 |
| 热重载 | 改了配置不用重启，机器人自己发现并用上新配置（最多等 60 秒）。 |
| 环境变量 | 电脑里存密码的一种地方，在命令行里用 `export` / `set` 设置，关机就没了。好处是密码不写进文件。小白可以直接在 Web 界面填，不用管这个。 |
| Ollama | 一个免费软件，让你在自己电脑上运行 AI 模型，不用联网、不用花钱。机器人默认用它当"大脑"。 |
| 反向代理 | 一种网络转发技术。小白不用懂——只有当你想让别人从外网访问你的 Web 界面时才需要。 |
| YAML | 配置文件用的格式，靠**空格缩进**表示层级。记住三大忌：冒号后加空格、不用 Tab、不用中文冒号。 |
| 插件 | 一个"翻译官"：每种论坛/聊天软件说话方式不一样，插件负责把它们翻译成机器人能懂的统一格式。 |
| 总览（Web 首页，原名"仪表盘"） | Web 界面第一个页面，能看到机器人正在管哪些社区、今天回了多少条。 |
| 梯度轮询 | 机器人按帖子活跃程度决定多久检查一次：刚有人说话的 1 分钟查一次，好几天没人说话的 7 天才查一次，省资源。 |
| 401 / 403 | 网站返回的"错误代码"，意思就是"你的登录过期了 / 没权限"。看到这个一般是 Token 填错了或过期了，重新申请一个就行。 |
| Bearer | 一种密码的传递方式，写在网络请求头里。小白不用懂，只要知道"把 Key 填到 Web 表单里就行"。 |
