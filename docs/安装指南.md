# 安装指南（小白专用）

> 这篇是给**第一次用命令行**的朋友写的。如果你已经会用 Python 和 pip，
> 可以直接看 [README](../README.md) 的快速开始。

先选你的系统，直接跳到对应章节：

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

---

## Windows

### 第 1 步：安装 Python

1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点黄色大按钮 **Download Python 3.x** 下载安装包
3. 双击安装包，**最重要的一步**：在安装界面底部勾选
   **"Add python.exe to PATH"**（把 Python 加到系统路径），然后点 Install Now
4. 安装完成后，按 `Win + R`，输入 `cmd`，回车，打开黑色命令窗口
5. 输入下面这行，回车，看到版本号就是成功了：

```
python --version
```

应该显示类似 `Python 3.12.3`。如果显示"不是内部或外部命令"，
说明第 3 步没勾选 Add to PATH，卸载重装一次，记得勾选。

### 第 2 步：下载项目

1. 打开 https://github.com/mentos523/community-bot
2. 点绿色 **Code** 按钮 → **Download ZIP**
3. 解压到一个你找得到的地方，比如 `D:\community-bot`
4. 在命令窗口里进入这个目录：

```
cd D:\community-bot
```

### 第 3 步：安装依赖

在命令窗口里输入（看到 Successfully 就是成功了）：

```
pip install -r requirements.txt
```

> 如果提示 `'pip' 不是内部或外部命令`，回到第 1 步检查 PATH。

### 第 4 步：复制配置

```
copy config\config.example.yaml config\config.yaml
```

然后用**记事本**打开 `config\config.yaml`（右键 → 打开方式 → 记事本，
**不要用 Word**），按里面的中文注释填写。实在看不懂可以先不动，
后面用 Web 界面配也行（见第 6 步）。

### 第 5 步：启动

双击 `start.bat`（项目根目录下），它会自动做：检查 Python →
安装依赖 → 提醒你设管理密码 → 启动机器人和 Web 界面。

或者手动分两步（需要开**两个**命令窗口）：

窗口 1（机器人本身）：
```
set WEB_PASSWORD=你的密码
python -m src.main
```

窗口 2（Web 管理界面）：
```
set WEB_PASSWORD=你的密码
python -m src.web.app
```

> **密码说明**：`WEB_PASSWORD` 是你登录 Web 管理界面的密码，
> 自己定一个就行，两个窗口要用**同一个**密码。

### 第 6 步：打开 Web 界面

浏览器访问 http://127.0.0.1:52323 ，输入刚才设的密码登录。
在"社区管理"里添加你的论坛/群，填上 Token，就跑起来了。

## macOS

### 第 1 步：安装 Python

1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点黄色大按钮下载 macOS 安装包，双击安装，一路"继续"
3. 打开**终端**（在"启动台"里搜"终端"），输入：

```
python3 --version
```

看到 `Python 3.x.x` 就是成功了。

> 注意：Mac 上命令是 `python3` 和 `pip3`（多个 3），不是 `python` / `pip`。

### 第 2 步：下载项目

```
cd ~
git clone https://github.com/mentos523/community-bot.git
cd community-bot
```

没装 git 的话：打开项目网址 → Code → Download ZIP → 解压 → 终端里 `cd` 进去。

### 第 3 步：安装依赖

```
pip3 install -r requirements.txt
```

### 第 4 步：复制配置

```
cp config/config.example.yaml config/config.yaml
```

用**文本编辑**打开 `config/config.yaml` 按中文注释填写（不会就先跳过，后面 Web 里配）。

### 第 5 步：启动

双击 `start.sh`（或在终端里运行 `bash start.sh`）。
或手动开两个终端窗口：

窗口 1：
```
export WEB_PASSWORD=你的密码
python3 -m src.main
```

窗口 2：
```
export WEB_PASSWORD=你的密码
python3 -m src.web.app
```

### 第 6 步：打开 Web 界面

浏览器访问 http://127.0.0.1:52323 ，登录后在"社区管理"里添加社区。

## Linux

### 第 1 步：安装 Python

Ubuntu / Debian：

```
sudo apt update
sudo apt install python3 python3-pip -y
python3 --version
```

看到版本号就是成功了。

### 第 2 步：下载项目

```
cd ~
git clone https://github.com/mentos523/community-bot.git
cd community-bot
```

### 第 3 步：安装依赖

```
pip3 install -r requirements.txt
```

### 第 4 步：复制配置

```
cp config/config.example.yaml config/config.yaml
```

用你喜欢的编辑器打开 `config/config.yaml`（新手推荐 `nano`，比 vim 好退出来）：

```
nano config/config.yaml
```

### 第 5 步：启动

```
bash start.sh
```

或手动开两个终端：

```
export WEB_PASSWORD=你的密码
python3 -m src.main
```

```
export WEB_PASSWORD=你的密码
python3 -m src.web.app
```

### 第 6 步：打开 Web 界面

浏览器访问 http://127.0.0.1:52323 。

## 三系统命令对照表

| 想干嘛 | Windows 命令提示符 | Windows PowerShell | macOS / Linux |
|--------|-------------------|-------------------|---------------|
| 设管理密码 | `set WEB_PASSWORD=你的密码` | `$env:WEB_PASSWORD="你的密码"` | `export WEB_PASSWORD=你的密码` |
| 看 Python 版本 | `python --version` | `python --version` | `python3 --version` |
| 装依赖 | `pip install -r requirements.txt` | `pip install -r requirements.txt` | `pip3 install -r requirements.txt` |
| 复制配置 | `copy config\config.example.yaml config\config.yaml` | `copy config\config.example.yaml config\config.yaml` | `cp config/config.example.yaml config/config.yaml` |

> **密码要设两次吗？** 两个终端窗口各设一次就行，设完当前窗口有效，
> 关掉窗口就没了——所以推荐用一键脚本 `start.sh` / `start.bat`，
> 它会一次性问你要密码，然后两个都启动好。
